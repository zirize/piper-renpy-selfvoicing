How It Works

Ren'Py calls espeak -v <voice> -a <amp> <text> whenever self-voicing is active. This project installs a wrapper script named espeak that intercepts those calls and redirects speech synthesis to Piper TTS instead. The audio is played back immediately via aplay.

Ren'Py never knows the difference — it still calls espeak, but now it sounds natural.

Installation

1

Install dependencies

sudo apt install alsa-utils wget
2

Create directories

mkdir -p $HOME/.local/share/piper/models
mkdir -p $HOME/.local/share/piper/scripts
mkdir -p $HOME/.local/bin
3

Download and extract Piper

wget https://github.com/rhasspy/piper/releases/download/v1.2.0/piper_amd64.tar.gz
tar xvfz piper_amd64.tar.gz --strip-components=1 -C $HOME/.local/share/piper
ln -sf $HOME/.local/share/piper/piper $HOME/.local/bin/piper
4

Download a voice model

wget "https://huggingface.co/rhasspy/piper-voices/resolve/v1.0.0/en/en_US/hfc_female/medium/en_US-hfc_female-medium.onnx?download=true" \
    -O $HOME/.local/share/piper/models/en_US-hfc_female-medium.onnx
wget "https://huggingface.co/rhasspy/piper-voices/resolve/v1.0.0/en/en_US/hfc_female/medium/en_US-hfc_female-medium.onnx.json?download=true" \
    -O $HOME/.local/share/piper/models/en_US-hfc_female-medium.onnx.json
5

Install the wrapper script

# Clone this repo (or download the script manually)
git clone https://github.com/zirize/piper-renpy-selfvoicing.git
cp piper-renpy-selfvoicing/piper_espeak_wrapper.sh $HOME/.local/share/piper/scripts/espeak
chmod +x $HOME/.local/share/piper/scripts/espeak
ln -sf $HOME/.local/share/piper/scripts/espeak $HOME/.local/bin/espeak
6

Test

espeak "Piper installation complete."

If you hear the voice, you're done! Launch a Ren'Py game and press V to enable self-voicing.

💡 $HOME/.local/bin is in PATH by default on Ubuntu 21.04+, Fedora, Arch, and most modern distros. If espeak is not found, run export PATH="$HOME/.local/bin:$PATH" or add it to your ~/.bashrc.

Optional: Auto-Advance

The wrapper can automatically press Space after each dialogue line finishes speaking, so you don't have to click — great for listening to a whole scene hands-free. 

sudo apt install xdotool
RENPY_MODE=1 ./YourGame
