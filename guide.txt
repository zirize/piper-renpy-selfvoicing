**Disclaimer:**
This guide is intended for regular users, not developers.

**Summary:**

Piper is considered one of the best free TTS (Text-to-Speech) engines for Linux. It is a fast, local neural text-to-speech system that delivers high-quality sound.

Ren'Py uses espeak to generate voice. This guide provides a method to use Piper with an espeak wrapper.

This guide uses the standalone Piper 1.2.0 binary (https://github.com/rhasspy/piper/releases/tag/v1.2.0). It needs no Python and starts in about 0.25 s per line; the newer Python package (piper-tts) takes about 0.95 s, and cannot be installed with "pip install --user" on recent Ubuntu/Debian.

The shortest way is the script in this repository:

    git clone https://github.com/zirize/piper-renpy-selfvoicing.git
    cd piper-renpy-selfvoicing
    ./install.sh

The steps below do the same by hand.

**Guide:**

Check that aplay, curl and git are installed:

    aplay --version
    curl --version
    git --version

If any is missing, install it (Ubuntu/Debian):

    sudo apt install alsa-utils curl git

Create the directories:

    mkdir -p $HOME/.local/share $HOME/.local/bin

Download Piper 1.2.0 and extract it. This creates $HOME/.local/share/piper with the piper binary, its libraries and espeak-ng-data:

    curl -L https://github.com/rhasspy/piper/releases/download/v1.2.0/piper_amd64.tar.gz \
        | tar xz -C $HOME/.local/share

Download a voice model and its config file, for example UK English (jenny_dioco):

    mkdir -p $HOME/.local/share/piper/models
    cd $HOME/.local/share/piper/models
    V=https://huggingface.co/rhasspy/piper-voices/resolve/main/en/en_GB/jenny_dioco/medium/en_GB-jenny_dioco-medium
    curl -L -O $V.onnx -O $V.onnx.json

Get the wrapper script and link it in as 'espeak':

    git clone https://github.com/zirize/piper-renpy-selfvoicing.git $HOME/.local/share/piper/scripts
    ln -sf $HOME/.local/share/piper/scripts/piper_espeak_wrapper.sh $HOME/.local/bin/espeak

If 'espeak' is not found afterwards, make sure ~/.local/bin is in your PATH:

    export PATH="$HOME/.local/bin:$PATH"

(Add this line to ~/.bashrc to make it permanent.)

Test the installation:

    espeak "Piper installation complete."

If you can hear the voice, the installation was successful. Launch a Ren'Py game and press V to turn on self-voicing.


**Changing the voice:**

Browse all voices at: https://rhasspy.github.io/piper-samples/

Download the .onnx and .onnx.json of the voice you want into $HOME/.local/share/piper/models. The path under https://huggingface.co/rhasspy/piper-voices/resolve/main/ is <lang>/<locale>/<name>/<quality>/<model>, for example:

    en/en_US/hfc_female/medium/en_US-hfc_female-medium

Then set the MODEL variable at the top of $HOME/.local/share/piper/scripts/piper_espeak_wrapper.sh:

    MODEL=en_US-hfc_female-medium

Ren'Py runs the script for every line, so the change takes effect on the next line.

Only voices with "phoneme_type": "espeak" in their .onnx.json work with Piper 1.2.0.

Some recommended models:
- en_GB-jenny_dioco-medium (default)
- en_US-hfc_female-medium
- en_US-amy-medium
- en_GB-cori-high
- en_GB-alba-medium
- en_GB-semaine-medium


**Optional: Korean voice**

Lines that contain Hangul are read with MODEL_KO (ko_KR-kss-medium). Install it with "./install.sh --korean", or download it from ko/ko_KR/kss/medium/ko_KR-kss-medium and fix its config once: the file was written by Piper 1.5.0, and Piper 1.2.0 stops with "Phonemes must be one codepoint" until the five multi-codepoint entries (aɪ aʊ ɔɪ eɪ oʊ) are removed from "phoneme_id_map". install.sh shows the few lines of Python that do it. The voice is licensed CC BY-NC-SA 4.0 (non-commercial).


**Optional: log of spoken lines**

    touch /run/user/$UID/espeak_log_text    # start logging
    rm /run/user/$UID/espeak_log_text       # stop

Lines are appended to /run/user/$UID/espeak_logs/espeak_output.log.


**Auto-advance (currently disabled)**

The wrapper contains code that presses Space after each line (needs xdotool, X11 only, and RENPY_MODE=1 when launching the game). It is disabled: the script exits right after playback. Delete the "exit 0" line after the piper command to re-enable it.
